Design Rationale (Press 'r' to hide)

The Goal: Status distribution at a glance + one-click filtering + obvious selection state.

1. Radio Cards

Explicit radio affordance leaves no ambiguity about single-select behavior. Floating badge pops but costs horizontal and vertical density.

2. Pill Toggle

Compact, familiar iOS pattern. The containing tray groups options as one unit. But selection state is weak—just white bg.

3–4. Chips, Text Count

Clean inline layout. Plain text count is quiet—doesn't draw the eye to the numbers. Border-only (3) vs full semantic (4) is about emphasis.

6. Chips + Badge, Full Semantic

Inline badge gives count visual weight, semantic border + bg on selection reinforces context. Horizontal scan line stays clean.

5. Chips + Badge, Border-Only

Same badge benefit as 6, but subtler selection. Less visual noise, but selected state less obvious.

7. Large + Floating Badge

High visual impact—badges really pop. But costs the most space (horizontal and vertical) and floating badges break the horizontal rhythm.

8. Icon + Count

Ultra-compact. Great for dense UIs. But requires users to learn icon meanings. Not ideal for primary navigation.
