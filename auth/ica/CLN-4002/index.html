Notes Governor Usage Thresholds

Enhanced user dropdown card showing note usage capacity. Thresholds: 0–74% blue (normal), 75–89% amber (warning), 90–100% red (critical/blocked). Progress bar color changes by state; count text stays neutral. Alert banner appears at 75%+. Red badge appears on topbar avatar at 90%+. Resets monthly.

Nested corner radii formula for visual harmony outer-radius = inner-radius + padding. Card: 4px inner + 8px padding = 12px outer. Alert banner: parent has 4px radius, 12px gap to alert, so 4 - 12 = negative → clamp to 4px. Attribution: Relative rounded corners.
